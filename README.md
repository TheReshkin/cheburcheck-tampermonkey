# cheburcheck-tampermonkey

Tampermonkey userscript (>= 5.5.0) that checks whether the current site's
domain is in TSPU block lists using https://cheburcheck.ru/.

Status: work in progress (v0.4.0, manual check only).

## Установка

Нужен [Tampermonkey](https://www.tampermonkey.net/) 5.5.0 или новее.

**[Установить скрипт в один клик](https://raw.githubusercontent.com/TheReshkin/cheburcheck-tampermonkey/main/cheburcheck.user.js)**

Tampermonkey сам предложит установку при открытии raw-ссылки на `.user.js`.

## Использование

1. Откройте любой сайт.
2. Нажмите на иконку Tampermonkey и выберите **«Проверить этот сайт на cheburcheck.ru»**.
3. Плашка в правом нижнем углу сначала покажет прогресс («ответили N из 26 сканеров»), а когда сканеры ответят, итоговый вердикт (заблокирован / не ограничен / ошибка). Динамическая проверка занимает до ~минуты.

При первом запуске Tampermonkey спросит разрешение на запросы к `cheburcheck.ru`
(`@connect`) — нужно разрешить.

### Проверка сторонних доменов

Пункт меню **«Проверить сторонние домены сайта»** проверяет домены, к которым страница
обращалась при загрузке (скрипты, картинки, `fetch`/XHR). Сбор доменов идёт локально и
ничего не отправляет, пока вы не выберете этот пункт. Проверка идёт по 2 домена
одновременно, результаты кэшируются на 3 часа, за один запуск проверяется не больше 40
доменов. Скрипт не видит запросы из iframe, воркеров и WebSocket.

После завершения всех проверок на плашке появляются кнопки **«Копировать результаты»** (текстовый отчёт: домен, вердикт, детали) и, если часть доменов не удалось проверить, **«Повторить неудачные»**.

### Лимиты API и ошибки

При ответе 429 скрипт уважает заголовок `Retry-After` (иначе пауза 10/20/40/60 с, до 4 повторов). Пауза общая для всех параллельных проверок, на плашке виден обратный отсчёт. Домены, которые не удалось проверить, помечаются как «не проверено» и не кэшируются.

## Как определяется вердикт

1. Статическая проверка (`/api/v1/check`) даёт списки и `id` проверки.
2. Скрипт ждёт динамическую проверку сканерами (`/api/v1/probe/<id>`, SSE) до события
   `done` и берёт итог голосованием сканеров по тем же правилам, что и сайт.
   Вердикт сканеров главнее списков (домен за заблокированным CDN может быть в списках,
   но сканеры считают его доступным). Если сканеры недоступны, используется результат списков.

## Приватность

Проверяемый домен (текущий сайт, а в режиме сторонних доменов и они) отправляется на
cheburcheck.ru, сервис сохраняет историю проверок. Скрипт ничего не делает сам по себе,
пока вы не запустите проверку.

## Планы

- автоматическая проверка при открытии страницы;
- настройки (исключения, включение/выключение автозапуска).
